## User Preferences

- Work must be available through a normal browser on restricted work PCs as well as unrestricted home Linux computers.
- Prefer low recurring cost and retain GitHub Free where practical; cloud environments must be disposable and recoverable from Git.
- Do the foundation work first: source/evidence inventory, power/ground reconstruction, engineering requirements and toolchain tests before electrical board design.
- Prefer simple serviceable automotive hardware over expensive software-dependent PDM systems.
- Favor precise measurement, clear documentation, and no unverified component or harness assumptions.
